## Постановка

$$\partial_t\mathbf u+(\mathbf u\cdot\nabla)\mathbf u
=-\rho^{-1}\nabla p+\nu\Delta\mathbf u,\qquad\nabla\cdot\mathbf u=0.$$

Неизвестные — скорость и давление в объёме следа. Начальная скорость
и изменяющиеся во времени граничные условия заданы по измерениям.
Для каждого пробного значения вязкости заново решается PDE. Оптимизатор
SciPy TRF минимизирует расхождение скоростей в 539 внутренних точках.
Правая часть уравнения представлена одним деревом из 16 вершин
и его матрицей смежности, с сохранением операций и порядка аргументов.

Используется один эксперимент: **случай 1L, водная модель ветротурбины**.
Измерения PTV/Shake-the-Box обработаны методом VIC#; это экспериментальные
поля, не DNS. Статья: [Hillestad et al., Physical Review Fluids 11, 014701 (2026)](https://doi.org/10.1103/9pwb-ky8n).
Данные: [DataverseNO, DOI 10.18710/SX0ZQT, V1](https://doi.org/10.18710/SX0ZQT), CC0.

## Быстрый запуск

Из корня репозитория, Python 3.12:

```sh
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pytest -q
python execute_preparation.py
```

Компактный фрагмент измерений включён в репозиторий, поэтому загрузка
полного архива не требуется. Ноутбук повторяет вычисления MAC,
а раздел FEniCSx читает отчёты уже выполненных запусков из `outputs/`.

Отдельные команды:

```sh
python run_experiment.py             # MAC: решение, подбор ν, контроль, сеточные проверки
python check_solver_accuracy.py      # аналитический тест при малой вязкости
python make_preparation.py           # заново создать ноутбук, без сохранённых выходов
python execute_preparation.py        # выполнить все ячейки и сохранить выходы
python execute_preparation.py --fenics-only  # обновить только сравнение FEniCSx
```

## FEniCSx

Используется DOLFINx 0.11.0: скорость P2, давление P1, IPCS,
полунеявная схема Crank–Nicolson с экстраполяцией AB2.
FEniCSx устанавливается отдельно от обычного Python-окружения:

```sh
conda env create --prefix ./.fenicsx --file environments/fenicsx.yml
conda activate ./.fenicsx
python run_fenics_experiment.py --phase check
python run_fenics_experiment.py --phase verify
python run_fenics_experiment.py --phase primary
python run_fenics_experiment.py --phase coarser
python run_fenics_experiment.py --phase finer
python run_fenics_experiment.py --phase half_dt
```

Точные версии установленных пакетов macOS arm64 сохранены в
[`environments/fenicsx-osx-arm64.lock`](environments/fenicsx-osx-arm64.lock).
Ограничения метода и настройка MPI описаны в [документации](docs/fenicsx.md).
Обычные тесты не требуют FEniCSx; его проверки запускаются отдельными фазами.

## Полученные результаты

После подбора вязкости, на одном и том же контрольном окне:

| Метод | Относительная ошибка L2 | RMSE скорости, м/с |
|---|---:|---:|
| MAC, основная сетка 36×24×24 | 24.46% | 0.03318 |
| FEniCSx P2/P1 IPCS, сетка 18×12×12 | 28.16% | 0.03820 |

В обоих случаях оптимум достиг верхней границы диапазона,
ν = 1.8 × 10⁻⁶ м²/с. Надёжное определение молекулярной вязкости не получено.
Контроль использует отдельное измеренное начальное поле и известные
измеренные границы: это условное воспроизведение течения, не автономный прогноз.
MAC вносит заметную численную диффузию; у текущей реализации IPCS
сохраняются значительная сильная дивергенция и зависимость от сетки.
Аналитические тесты не являются вторым экспериментальным набором.

История постановок и использование ИИ записаны в
[`metadata/ai_provenance.json`](metadata/ai_provenance.json).
